キャッチ＆コネクト オンライン対戦プロトタイプ

必要なもの
- Node.js 18以降
- npm

ローカル起動（Windows PowerShell）
1. このフォルダーを VS Code で開く
2. ターミナルで npm.cmd install
3. ターミナルで npm.cmd start
4. ブラウザーで http://localhost:3000 を開く

遊び方
- 最初の人が「部屋を作る」を押します。
- 表示された部屋コードを他の人へ伝えます。
- 参加者は部屋コードを入力して「参加する」を押します。
- ホストが「ゲーム開始」を押すと、空席はCPUになります。
- 2～4人の人間プレイヤーを想定しています。1人で動作確認することもできます。

オンライン公開の手順はローカルでテストした後に行います。

注意
これは既存HTMLのルールを移植した初期プロトタイプです。複数ブラウザーで対戦し、特殊能力（特にブレイク）・キャッチ・コネクト・山札切れ・勝敗処理をテストしてください。
